# 🎵 ربات جستجوی موسیقی تلگرام

ربات تلگرام برای جستجوی موسیقی در کانال و اینترنت

## 📋 ویژگی‌ها

- 🔍 جستجوی موسیقی در کانال تلگرام
- 🌐 جستجوی موسیقی در اینترنت (در صورت عدم وجود در کانال)
- 📤 ارسال موسیقی برای کاربران
- 🎵 پشتیبانی از پیش‌نمایش موسیقی
- 💬 رابط کاربری فارسی

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- Node.js نسخه 14 یا بالاتر
- یک ربات تلگرام (توکن ربات)
- یک کانال تلگرام برای موسیقی

### مراحل نصب

1. **کلون کردن پروژه:**
```bash
git clone https://github.com/shehneh/tanziir-join-miniapp.git
cd tanziir-join-miniapp
```

2. **نصب وابستگی‌ها:**
```bash
npm install
```

3. **تنظیمات:**

فایل `.env` را ایجاد کنید و اطلاعات زیر را وارد کنید:

```env
# توکن ربات تلگرام (از @BotFather دریافت کنید)
BOT_TOKEN=your_telegram_bot_token_here

# آدرس کانال (مثال: @tanziir)
MUSIC_CHANNEL=@your_channel_username

# شناسه کاربری ادمین (اختیاری)
ADMIN_USER_ID=your_admin_user_id
```

### 🔑 دریافت توکن ربات

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید
2. دستور `/newbot` را ارسال کنید
3. نام و نام کاربری ربات را وارد کنید
4. توکن دریافتی را کپی کنید و در فایل `.env` قرار دهید

### ▶️ اجرای ربات

```bash
npm start
```

یا برای توسعه:

```bash
npm run dev
```

## 📖 نحوه استفاده

### دستورات ربات

- `/start` - شروع کار با ربات
- `/help` - نمایش راهنما
- `/search <نام آهنگ>` - جستجوی موسیقی

### جستجوی موسیقی

برای جستجو، کافی است نام آهنگ یا خواننده را ارسال کنید:

```
عماد طالب زاده
```

یا

```
دلم گرفته
```

ربات به ترتیب زیر عمل می‌کند:
1. ابتدا در کانال شما جستجو می‌کند
2. اگر پیدا نکرد، در اینترنت جستجو می‌کند
3. نتایج را برای شما ارسال می‌کند

## ⚙️ تنظیمات پیشرفته

### جستجو در کانال

برای فعال کردن جستجوی کانال:

1. ربات را به عنوان ادمین به کانال اضافه کنید
2. به ربات دسترسی خواندن پیام‌ها بدهید
3. کد را برای ذخیره و ایندکس پیام‌های کانال توسعه دهید

**نکته:** پیاده‌سازی کامل جستجوی کانال نیاز به یک دیتابیس یا کش برای ذخیره پیام‌های کانال دارد.

### استفاده از APIهای دیگر

می‌توانید از APIهای مختلف برای جستجوی موسیقی استفاده کنید:

- iTunes Search API (پیش‌فرض - رایگان)
- Spotify API (نیاز به احراز هویت)
- Deezer API
- YouTube API

## 🛠️ توسعه

### اضافه کردن قابلیت‌های جدید

برای توسعه ربات می‌توانید:

1. توابع جستجوی جدید اضافه کنید
2. APIهای دیگر را پیاده‌سازی کنید
3. دیتابیس برای ذخیره تاریخچه جستجو اضافه کنید
4. سیستم نظرسنجی کاربران را پیاده کنید

### تست

برای تست ربات:

```bash
# ربات را اجرا کنید
npm start

# در تلگرام با ربات چت کنید و قابلیت‌ها را امتحان کنید
```

## ⚠️ نکات مهم

1. **حریم خصوصی:** از ارسال موسیقی‌های دارای حق نشر به صورت غیرقانونی خودداری کنید
2. **محدودیت‌ها:** API تلگرام محدودیت در تعداد پیام و حجم فایل دارد
3. **کانال:** برای جستجوی کامل در کانال، ربات باید ادمین باشد
4. **منابع:** از منابع قانونی برای دریافت موسیقی استفاده کنید

## 🐛 عیب‌یابی

### مشکلات رایج

**ربات پاسخ نمی‌دهد:**
- توکن ربات را بررسی کنید
- اتصال اینترنت را چک کنید
- لاگ‌ها را بررسی کنید

**جستجو کار نمی‌کند:**
- اتصال به اینترنت را بررسی کنید
- APIهای خارجی ممکن است فیلتر باشند
- از VPN یا پروکسی استفاده کنید

**فایل صوتی ارسال نمی‌شود:**
- حجم فایل را بررسی کنید (حداکثر 50MB)
- فرمت فایل باید معتبر باشد
